# Hangman Game

A simple Hangman-style word guessing game built with React.

This project was created while following a Scrimba React course and helped me practice React fundamentals such as state management, event handling, conditional rendering, and working with arrays.

## Features

- Guess the hidden word by selecting letters
- Displays correctly guessed letters
- Tracks incorrect guesses
- Shows remaining attempts
- Displays the game result when the player wins or loses
- Option to start a new game

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
